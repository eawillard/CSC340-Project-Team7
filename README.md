## Description 
> LibraryPal is a platform that simplifies local libraries by helping users connect to the nearest one, allowing for more convenient ways to request books, schedule pick ups / drop offs, and take part in community efforts by donating books or leaving reviews. The system also supports providers who want to attract more readers and students to give them a more convenient experience.

## App Functions
1. Customer:
    1. Create/modify customer profile 
    2. Request and browse available books
    3. Schedule pick up / drop off
    4. Write reviews for book
    5. Search for local library
2. Provider:
    1. Create/modify/remove provider profile 
    2. Add/Remove books
    3. View customer statistics (requested books, view donations)  
    4. Reply to reviews
    5. Connect user to local library
